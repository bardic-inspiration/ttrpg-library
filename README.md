# TTRPG Content Library

A static gallery of original D&D 5e content built on the SRD 5.2: creatures,
magic items, and spells, generated by Claude routines from GitHub Issues,
reviewed as pull requests, and published to GitHub Pages on merge. Browse,
filter, and search the library, and export any entry as JSON, PNG, or a
print-ready page.

## Status

Being built toward v1. The delivery plan is [`SPEC.md`](SPEC.md) §16; each
milestone is tracked as a GitHub issue.

## How this repo is built

This project is built largely by AI coding sessions — some interactive, some
running on a schedule — in small, verifiable steps:

- **The task is the prompt, the PR is the response, review is the evaluation,
  and the squash commit on `main` is the record.**
- [`SPEC.md`](SPEC.md) is the source of truth for what to build.
- Work runs in two lanes: **content** (entries, opened by routines) and
  **development** (everything else, opened by sessions you start). CI keeps
  them apart.
- Every change passes the `validate` check, and a human merges it.

Agents and humans starting fresh should read [`AGENTS.md`](AGENTS.md) first.

## Development

Node 22 LTS and npm. Then:

```bash
git clone https://github.com/bardic-inspiration/ttrpg-library
cd ttrpg-library
npm ci
npm run dev
```

The rest of the commands, and how work is done here, are in
[`AGENTS.md`](AGENTS.md).
